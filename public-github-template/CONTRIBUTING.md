# Contributing to OTYA public resources

Thanks for helping improve Otya.

This public repository is for documentation, reproducible public bug reports, feature requests, release information and public examples. Otya production application/backend source remains private.

## Before opening an issue

- Check the current Otya Docs: https://petersmartlink.com/docs
- Use the latest supported Otya Media release when possible.
- Do not include passwords, OTPs, access tokens, API keys, private files or personal account data.
- Security vulnerabilities must be reported privately according to `SECURITY.md`.

## Bug reports

Include the Otya product, app version/build, Android/device version when relevant, what you expected, what happened, and the smallest safe reproduction steps.

## Feature requests

Describe the problem you want solved before proposing an implementation. Explain who benefits and whether the feature needs internet/account access or should work offline.

## Pull requests

Public pull requests may improve documentation, examples or explicitly public SDK/sample code. Do not submit copied proprietary Otya production source, secrets, private configuration or reverse-engineered internal code.

By contributing, you confirm that you have the right to submit the material and agree that the contribution may be used under the license stated for the relevant public files.
